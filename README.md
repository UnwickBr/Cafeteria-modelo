# Café Aurora ☕

Landing page demonstrativa de uma cafeteria artesanal.

## Como visualizar

Abra `index.html` no navegador ou publique a branch `main` no GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Recursos

- Layout responsivo
- Hero com vídeo de fundo e imagem de reserva
- Cardápio ilustrativo
- Seções sobre, ambiente e contato
- Animações suaves com suporte a movimento reduzido

## Antes de usar comercialmente

Substitua preços, cardápio, informações de contato e fotos/vídeo por dados e mídias autorizados da cafeteria. O endereço de e-mail atual é um placeholder.

Projeto demonstrativo criado para personalização.
